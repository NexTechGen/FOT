# Content Update Checklist
**Department of Engineering Technology Website**

Use this checklist to ensure all content updates are complete and accurate.

## Pre-Update
- [ ] Identify what needs to be updated
- [ ] Gather accurate information (names, titles, emails, phone numbers)
- [ ] Prepare images in correct format and size
- [ ] Create a backup of files you're editing

## General Content Updates

### Contact Information
- [ ] Update address in `assets/js/content.js`
- [ ] Update phone number and email
- [ ] Update Google Maps embed URL if location changed
- [ ] Update social media links
- [ ] Test contact page displays correctly

### Homepage
- [ ] Verify department intro is current
- [ ] Check faculty intro is up to date
- [ ] Review academic overview tiles
- [ ] Verify facilities section shows correct items
- [ ] Check news section displays latest items

### About Page
- [ ] Update Dean's message if changed
- [ ] Update Head of Department's message
- [ ] Verify vision and mission statements are approved
- [ ] Review department history and milestones
- [ ] Confirm academic organisation description is accurate

## Staff Updates
- [ ] Add new staff to `assets/js/staff.js` with all required fields
- [ ] Update existing staff information
- [ ] Remove/former staff handled appropriately
- [ ] Only one person marked as `isHeadOfDepartment: true`
- [ ] Staff photos added to `assets/images/staff/` and referenced correctly
- [ ] Specialisation assignments are correct
- [ ] Study leave status updated if applicable
- [ ] Coordinators properly assigned
- [ ] Staff directory displays correctly

## Specialisations
- [ ] Update specialisation overview text
- [ ] Update curriculum for correct academic year
- [ ] Verify coordinator is assigned correctly
- [ ] Check specialisation images are current
- [ ] Update research summary
- [ ] Add/update programme documents if available
- [ ] Specialisation pages render correctly

## Research
- [ ] Add new publications to `assets/js/research.js`
- [ ] Update publication details (authors, venue, year)
- [ ] Add links where available
- [ ] Assign to correct specialisations
- [ ] Set correct status (Published/In Press/etc.)
- [ ] Research page filters work correctly

## News & Events
- [ ] Add new news items with correct date (YYYY-MM-DD format)
- [ ] Write clear summary and body
- [ ] Add images if available
- [ ] Set appropriate category
- [ ] Remove outdated news if necessary
- [ ] News page and homepage display correctly

## E-Resources/Downloads
- [ ] Add new documents to appropriate sections
- [ ] Update file names, formats, and sizes
- [ ] Verify download links work
- [ ] Programme documents auto-collected from specialisations
- [ ] All sections display properly

## Images & Assets
- [ ] Images optimized for web (reasonable file size)
- [ ] Correct filenames (lowercase, hyphens, no spaces)
- [ ] Placed in correct directories
- [ ] Alt text provided where applicable
- [ ] No broken images on any page

## Quality Assurance
- [ ] Check all modified pages in browser
- [ ] Test on mobile/responsive view
- [ ] Verify navigation links work
- [ ] Check for JavaScript errors (browser console)
- [ ] Ensure no placeholder text remains in published content
- [ ] Verify contact details are accurate
- [ ] Test all internal and external links
- [ ] Check footer displays correctly on all pages

## Post-Update
- [ ] Clear cache and test again
- [ ] Document changes made
- [ ] Notify relevant staff of updates
- [ ] Keep backup of modified files
- [ ] Verify deployment if live site

---

**Note:** Always ensure content is approved by the appropriate department authority before publishing.
